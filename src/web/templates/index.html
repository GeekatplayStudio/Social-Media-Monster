SocialMediaMonster System Architecture

  • • Core Logic & Orchestration: Python 3.12, FastAPI, SQLModel, SQLite persistent database.
  • • Abstract API Provider Layer: Unified abstract interface routing to Local Ollama, OpenAI, Google Gemini, and Anthropic Claude.
  • • ComfyUI Idiogram Engine: High-contrast editorial visual card generator with bounding box coordinates and prompt dispatch.
  • • MCP Protocol Server: Standardized AI Model Context Protocol exposing agent tools for system control.
  • • Temporal Persistent State Recovery: SQLite checkpointing engine recording worker execution stages (RESEARCH, VERIFICATION, COPYWRITING, QA_VALIDATION, VISUAL_GENERATION, PUBLISHING). If server restarts or page closes, state is automatically restored.
